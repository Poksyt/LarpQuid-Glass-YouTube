# How to Install LarpQuid Glass

## Step 1: Download the ZIP File

Download the extension’s `.zip` file to your computer and save it somewhere easy to find, such as your Downloads folder.

## Step 2: Extract the ZIP File

Before installing the extension, you’ll need to extract the ZIP file.

1. Find the ZIP file you downloaded.
2. Right-click it and select **Extract All** on Windows. On macOS, double-click the ZIP file.
3. Remember where the extracted folder is saved. You’ll need it in a later step.

## Step 3: Open Your Browser’s Extensions Page

Open your Chromium-based browser, such as Chrome, Microsoft Edge, or Brave.

Next, enter the appropriate address in the address bar:

- **Chrome:** `chrome://extensions/`
- **Microsoft Edge:** `edge://extensions/`
- **Brave:** `brave://extensions/`

Press **Enter** to open the Extensions page.

## Step 4: Enable Developer Mode

Find the **Developer mode** toggle on the Extensions page and turn it on. It’s usually located in the top-right corner.

This allows you to install extensions directly from a folder on your computer.

## Step 5: Install the Extension

Now you’re ready to install the extension.

1. Click **Load unpacked**.
2. Find and select the folder you extracted earlier. Make sure the folder contains the `manifest.json` file.
3. Click **Select Folder** or **Open**, depending on your operating system.

Your browser should load the extension and display it on the Extensions page.

## Step 6: Done — LarpQuid Glass is ready

That’s it! The extension is installed just open YouTube to see the difference

You can customize the extension by clicking its icon in the browser’s extensions menu.
